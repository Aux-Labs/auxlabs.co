No file, no photo: the placeholder stays. The green/mono treatment is CSS,
so use an ordinary photo, no Photoshop needed.

Before a phone photo goes in: resize to ~1600px wide and strip location
data. squoosh.app does both in the browser (it drops EXIF/GPS by default).
